# Processamento_de_imagens
Projetos da matéria de processamento de imagem
## Lista dos códigos
1. Introdução a processamento de dados
* Codigo simples introduzindo algumas funções de processamento de imagem    
2. Aquisicao_de_imagens
* Continuação do primeiro codigo usando outros conversões de cor de imagens e usando matriz de ax para plotar imagens
3. Quantificacao_imagen + quantização.Entrega
* Trabalho feita para treinar quantificação e imagem criada em resolução ao trabalho
4. AulaHistogramaDeImagens11_09
* Criação de histograma para a quantificação de pixels em uma imagem
5. Trabalho_imagens
* Trabalho que consistiu em histograma de 3 tipos de fotos, consições normais de luz, pouca luz e muita luz, e quantificar os pixels em hisotgramas e analisar uma operção para melhorar a qualidade das 3 imagens ao mesmo tempo
